# Manas Lifestyle Resort — website rebuild (2026)

A fast, custom static website for manaslifestyleresort.in. HTML, CSS and vanilla JavaScript, with GSAP, ScrollTrigger, Lenis, SplitType and Swiper. It is generated by a small Node build, so every page is plain HTML that search engines can read without running JavaScript.

## Structure
```
build/            generator + data (edit content here, then rebuild)
  data/site.mjs     contacts, address, booking engine, analytics IDs  ← single source of truth
  data/rooms.mjs    9 room types + 4 villas (facts only)
  data/content.mjs  reviews, activities, venues
  pages/*.mjs       page templates and copy
  lib.mjs           shared header, footer, booking bar, forms, schema
  build.mjs         renders site/ + sitemap.xml, robots.txt, .htaccess, _redirects
  audit.mjs         pre-launch SEO and link audit
  serve.mjs         local preview (simulates the enquiry API)
site/             THE DEPLOYABLE WEBSITE (upload this folder)
  css/main.css  js/main.js + js/modules/*  images/  api/enquiry.php
docs/             SEO baseline, URL migration map, keyword map, asset inventory
```

## Commands
```bash
cd build && npm install            # once (installs sharp for image work)
node build/optimize-images.mjs     # only when photos change (assets-src/img → site/images)
node build/build.mjs               # regenerate all pages
node build/audit.mjs               # must report "No issues found." before deploy
node build/serve.mjs 4321          # preview at http://localhost:4321
```

## What's built
- 74 pages: Home, About, Accommodation hub, 9 room pages (`/rooms/…`), Villas hub, 4 villa pages (`/villas/…`), Experiences (`/facilities/`), Dining, In-room dining, Weddings, Banquets, Corporate, School picnics, Services, Gallery, Offers, Location (new), Contact, FAQ, Privacy, Terms, HTML sitemap, Journal + all 39 existing articles, 404.
- **All 56 existing URLs are kept exactly** (audit checks this). Redirects only cover WordPress leftovers and 123 indexed image URLs. Menu PDFs stay at their old `/wp-content/uploads/2025/09/` paths.
- Structured data: Hotel/Resort, Organization, WebSite, WebPage, BreadcrumbList, HotelRoom/Suite/House, Restaurant/BarOrPub, EventVenue, FAQPage (only where the Q&A is on the page), BlogPosting, ImageGallery.
- Motion: preloader (first visit only, ≤1 s), split-text headlines, clip-path image reveals, parallax, a pinned horizontal Experiences section (desktop only), magnetic buttons, custom cursor (mouse only), page-curtain transitions, counters for published figures only. All of it is switched off for `prefers-reduced-motion`, and the page works if the scripts fail.
- Booking: the booking bar hands off to the existing Simplotel engine (`bookings.manaslifestyleresort.in`, property 6207, promo `manas15`). There is no fake confirmation anywhere.
- Enquiry forms for accommodation, wedding, banquet, corporate, school and general enquiries. They validate in the browser, have a honeypot field, a minimum fill time and a per-IP rate limit, route to the right desk, and fall back to WhatsApp if sending fails.
- Three.js and Lottie were deliberately not used: there was no meaningful 3D or vector-animation need, and leaving them out keeps the site fast.
